# Talent Foxes

Приложение для детей: двигайся, наводи порядок в комнате и расти питомца. У родителей есть кабинет с заданиями и баллами.

- Родители входят через Google (до двух на семью).
- Каждый ребёнок входит по своему логину и паролю. У каждого свои задания, награды, питомец и плейлисты.
- Русский, английский и греческий, цвет темы выбирает ребёнок.
- Данные хранятся в Firebase (Authentication и Firestore).

## Как это устроено

Веб-приложение на Vite и обычном JavaScript, упаковано в Android через Capacitor. APK собирает GitHub Actions
(`.github/workflows/android.yml`). Готовый APK каждый раз публикуется на странице
[Releases / latest](https://github.com/Andrey6570/talentfoxes/releases/latest): откройте её на телефоне и скачайте `talent-foxes.apk`.

```
src/             интерфейс и логика
firestore.rules  правила доступа к базе
android/         проект Android (Capacitor)
```

## Первый запуск

1. Firebase Console → Firestore Database → **Rules**: вставьте содержимое `firestore.rules` и нажмите **Publish**.
2. Firebase Console → Project settings → Your apps → Android → **Add fingerprint**: вставьте SHA-1 ключа подписи (ниже),
   затем скачайте новый `google-services.json` и замените `android/app/google-services.json`.
3. Authentication → Sign-in method: включены Google и Email/Password.

Ключ подписи `android/app/talentfoxes.jks` лежит в репозитории (по решению владельца, репозиторий приватный). Им подписаны отладочная и
релизная сборки, поэтому SHA-1 не меняется. Если репозиторий станет публичным, ключ нужно заменить. SHA-1:

```
B7:B0:96:17:4C:AB:79:E8:83:70:6C:22:21:95:1C:B3:CC:49:92:13
```

## Как работает вход ребёнка

Firebase не умеет входить по логину, поэтому ребёнок входит по служебному адресу
`логин__кодсемьи@kid.talantfoxes.app`. Родитель создаёт ребёнка в кабинете: имя, логин латиницей, пароль от 6 символов.
Ребёнок вводит код семьи (он показан в кабинете родителя), логин и пароль. Код и логин запоминаются на устройстве.
Смена пароля создаёт новый служебный адрес, старый перестаёт работать.

## Данные в Firestore

```
invites/{код}                        fid
logins/{код__логин}                  fid, v (версия служебного адреса)
families/{fid}                       name, parentUids[], inviteCode
families/{fid}/shared/rules          правила семьи (взносы)
families/{fid}/shared/pot            семейная копилка: сумма и цель
families/{fid}/kids/{kidId}          профиль, питомец, задания, награды, плейлисты, серия
families/{fid}/kids/{kidId}/log      отправленные и подтверждённые задания, бонусы
families/{fid}/kids/{kidId}/orders   покупки наград и одежды
```

Баланс звёзд считается из `log` и `orders`: подтверждённые задания и бонусы минус покупки.

## Справка в приложении

В «Настройки → Справка» лежат пошаговая инструкция и частые вопросы для родителей и для ребёнка, на русском, английском и
греческом. Тексты в `src/help.js` (русский служит ключом, переводы в файлах i18n). Там же кнопка «Показать приветствие снова».

## Языки

Исходный текст русский и служит ключом: английский лежит в `src/i18n.js` и `src/i18n-more.js`, греческий в `src/i18n-el.js`.
Если греческой строки нет, показывается английская. Греческий написан нейтрально по роду, но перед публичным выпуском его
должен прочитать носитель языка. Страницы политики и условий пока только на русском и английском, в приложении для греческого
открываются английские.

## Календарь и напоминания

У заданий есть расписание: дни недели и время (например, танец по понедельникам и средам в 17:00), у разовых ещё срок. Родитель
добавляет семейные события (с повтором раз в неделю или раз в год и выбором, для кого), ребёнок видит свою неделю во вкладке
«Календарь». Напоминания по расписанию (за 10 минут до события, в нужное время для задания, в 09:00 для событий на весь день)
планируются на самом телефоне на 7 дней вперёд, поэтому приходят и при закрытом приложении, с точностью до нескольких минут.
Кнопка «В Google Календарь» открывает готовую форму события, вход и ключи не нужны. События хранятся в
`families/{fid}/events/{id}`.

## Push-уведомления (тариф Blaze)

Серверная часть лежит в `functions/` (Cloud Functions, Node 22, регион `eur3`). Она шлёт уведомления через Firebase Cloud
Messaging и убирает за собой записи входа детей:

| Событие в базе | Кому уведомление |
|---|---|
| ребёнок отправил задание (в том числе спидран и ремонт) | всем устройствам родителей, с именем ребёнка |
| ребёнок выбрал награду | всем устройствам родителей, с именем ребёнка |
| родитель подтвердил задание | устройствам этого ребёнка |
| родитель добавил ребёнку задание | устройствам этого ребёнка |
| удалён профиль ребёнка или сменён пароль | удаляется его запись входа в Authentication |

Устройства регистрируются в `families/{fid}/devices/{id}` (токен, язык, роль). Текст уведомлений берётся из тех же словарей, что
и приложение (`functions/i18n.json`, создаётся командой `node tools/build-functions-i18n.mjs` после правки переводов), на языке,
выбранном на устройстве. Напоминания по расписанию по-прежнему планируются на самом телефоне.

**Первая настройка.**
1. Firebase Console → внизу слева план Spark → **Upgrade** → Blaze (нужна банковская карта). В Google Cloud → Billing →
   Budgets & alerts создайте бюджет на 5 € с оповещением по почте.
2. Google Cloud Console → IAM и администрирование → Сервисные аккаунты → создайте аккаунт `github-deploy`, дайте ему роль
   **Владелец** (Owner) в проекте `talent-foxes`, создайте ключ JSON.
3. GitHub → Settings → Secrets and variables → Actions → секрет `FIREBASE_SERVICE_ACCOUNT` со всем текстом ключа.
4. Actions → «Deploy Firebase» → Run workflow. Он же публикует `firestore.rules`, вставлять их вручную больше не нужно.
5. Поставьте свежий APK, разрешите уведомления.

Если первая выкладка остановилась на разрешениях Eventarc, подождите 5–10 минут и запустите её снова: права появляются не сразу.

## Правила семьи и копилка

Вместо штрафов есть «взнос в копилку». Правило с заранее известной ценой (1–3 ★) родитель применяет к ребёнку.
Первый раз за неделю это только напоминание. Со второго раза звёзды уходят в общую семейную копилку, но не больше 3 ★
за раз, не больше 20% от заработка ребёнка за неделю, и баланс не уходит ниже нуля. У правила может быть «ремонт»:
если ребёнок выполнит его за 24 часа и родитель подтвердит, звёзды возвращаются. Взнос можно отменить.

## Публикация в магазинах

**Юридические страницы.** В папке `legal/` лежат политика конфиденциальности и условия на русском и английском. Это шаблоны:
заполните места, выделенные цветом (имя или компания, адрес, почта, дата), покажите текст юристу и выложите папку на публичный
адрес (например, GitHub Pages из отдельного публичного репозитория). Затем впишите адрес со слэшем в конце в `LEGAL_URL`
(`src/config.js`). После этого ссылки появятся в приложении, а адреса страниц пригодятся для анкет магазинов.

**Согласие и удаление данных.** При создании семьи и ребёнка родитель подтверждает согласие (версия записывается в данные).
В «Настройки → Данные и удаление» можно удалить семью со всеми данными или выйти из семьи, а профиль ребёнка удаляется в кабинете
родителя. Если при удалении ввести пароль ребёнка, удаляется и его запись входа. Полностью убирать записи входа без пароля сможет
серверная функция (понадобится тариф Blaze).

**Подпись для Google Play.** Это отдельный ключ загрузки, его нет в репозитории. В GitHub → Settings → Secrets and variables →
Actions добавьте секреты `UPLOAD_KEYSTORE_BASE64` и `UPLOAD_KEYSTORE_PASSWORD`. Затем Actions → «Android release bundle» →
Run workflow, и артефакт `talent-foxes-aab` загружается в Play Console. Включите Play App Signing. После первой загрузки добавьте
SHA-1 сертификата подписи приложения из Play Console (Setup → App integrity) в Firebase, иначе вход через Google в версии из
магазина не заработает. APK для семьи собирается по-прежнему старым ключом, поэтому его нельзя обновить поверх версии из магазина:
сначала удалите приложение.

## Разработка

```
npm install
npm run dev        # веб-версия в браузере
npm run sync       # собрать веб и обновить android/
```

Сборка APK локально требует Android SDK и JDK 21: `cd android && ./gradlew assembleRelease`.

## Известные ограничения

- Баланс считается на устройстве, поэтому технически ребёнок мог бы создать заказ без достаточного баланса.
  Родитель видит каждый заказ и может отказать с возвратом звёзд.
- Ключ подписи хранится в репозитории: APK предназначен для установки в семье, в магазин с этим ключом выкладывать нельзя.
- Spotify и Яндекс Музыка подключены по ссылкам на плейлисты. Вход в Spotify добавим позже.
